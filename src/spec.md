# Specification

## Summary
**Goal:** Modernize the Home page visuals by upgrading the banner slider designs and replacing game icons with more realistic, modern image-based visuals, while keeping existing asset paths and behavior unchanged.

**Planned changes:**
- Replace the 3 Home banner carousel images (Ludo, Chess, Carrom) with new, more realistic/modern designs, while keeping the carousel behavior and the exact same filenames/paths used by the component.
- Replace the HomeScreen “All Games” grid icon images for Ludo/Chess/Carrom with more realistic/modern icons, while keeping the exact same filenames/paths.
- Update the Quick Play section to match the provided reference style by using the same image icons for Ludo/Chess/Carrom (instead of Lucide vector icons), while preserving existing Quick Play text, 3-item grid layout, and `onSelectGame(game)` navigation behavior.

**User-visible outcome:** The Home carousel, All Games icons, and Quick Play tiles look more modern and realistic (closer to the reference image), while navigation and game selection continue to work exactly as before with only Ludo/Chess/Carrom shown.
